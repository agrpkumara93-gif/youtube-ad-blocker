YouTube Ad Blocker - Chrome/Edge Extension

Features
- Automatically clicks visible YouTube Skip Ad buttons.
- Hides common ad banners, overlays, promoted items, and ad containers.
- Optionally fast-forwards player ads that do not expose a skip button.
- Popup switches for each feature.

Installation
1. Unzip youtube-ad-blocker.zip.
2. Open chrome://extensions/ or edge://extensions/.
3. Enable Developer mode.
4. Click Load unpacked.
5. Select the extracted youtube-ad-blocker folder.
6. Refresh any YouTube tabs already open.

Notes
- YouTube changes its DOM frequently, so selectors may eventually need updates.
- If playback behaves strangely, disable Fast-forward unskippable ads.
